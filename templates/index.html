💻 Apuntes de Comandos y Procedimientos

Guía rápida de comandos de soporte técnico con copia a un solo clic.

📦 1) Comando paqueterías 

for repo in cacheton python3_cacheton pcinnovex; do hg -R /opt/software/${repo}/ parents --template "${repo}: \033[92m{rev}:{node|short}\033[0m {desc|firstline}\n" 2>/dev/null; done
Batería de nodos:
tail -300 /var/log/cacheton/jenreceiver_07_2026.log | grep -a ':NODE'
Voltajes y paquetería:
tail -300 /var/log/cacheton/jenreceiver_08_2026.log | grep -a ':NODE' && for repo in cacheton python3_cacheton pcinnovex; do hg -R /opt/software/${repo}/ parents --template "${repo}: \033[92m{rev}:{node|short}\033[0m {desc|firstline}\n" 2>/dev/null; done

🔍 2) Revisar y filtrar logs 

tail -91000 /var/log/cacheton/jenreceiver_08_2026.log | grep -a -E ':3:0:(OXY|NODE)'

🔄 3) Revisar sincronización de cacheton

Ejecutar sincronización:
sudo /usr/bin/tcp_sync_cacheton -fv
Ver log en tiempo real:
tail -f /var/log/cacheton/tcp_sync_cacheton.log

📷 4) Comandos cámara

Editar configuración:
sudo nano /etc/visibility-cam/camconf.conf
Ver log (Servicio local):
tail -f /var/log/visibility-cam-photo.log
Ver log (Sincronización):
tail -f /var/log/visibility-cam-sync.log

🎥 Ver imagen de la cámara

Opción 1 (GStreamer):
gst-launch-1.0 rtspsrc location=rtsp://admin:1234webcam@IP-CAM:554/Streaming/Channels/1 latency=300 ! decodebin ! autovideosink
Opción 2 (FFplay):
ffplay rtsp://admin:1234webcam@IP-CAM:554/Streaming/Channels/1

⏱️ 5) Tiempo encendido pc 

uptime -s

🌐 6) Dataweb

Reload:
http://dataweb.innovex.cl:8888/prueba_membrana/reload/
Parámetro:
http://dataweb.innovex.cl:8888/mef-taraba8-inyeccion/node/

🌤️ 7) Estación meteorológica

Davis

Configuración 1.1.1:
cat /var/lib/weather_station/weather_station.toml
Configuración 1.1.2:
sudo nano /var/lib/weather_station/config.toml
Reiniciar servicio:
sudo systemctl restart weather_station_davis.service
Ver log de Davis:
tail -f /var/log/cacheton/weather_station_davis.log

Airmar

Ver log de Airmar:
tail -f /var/log/cacheton/weather.log

⚡ 8) Comando para saber cuándo se apagó y encendió el PC 

journalctl --since "48 hours ago" | grep -E "systemd-shutdown|Linux version" | awk '
/systemd-shutdown/ {print "🟥 Apagado:", $1, $2, $3, $4}
/Linux version/    {print "🟩 Encendido:", $1, $2, $3, $4}
'

🛡️ 9) Allowed host. Agregar.

Pc innovex

sudo sed -i '/ALLOWED_HOSTS/s/.$/, "10.9.31.221"]/' /var/lib/pcinnovex/pcinnovex/settings.py
Reiniciar Apache2:
sudo systemctl restart apache2.service

Pc innovex 2

sudo sed -i '/ALLOWED_HOSTS/s/.$/, "10.5.24.35"]/' /var/lib/pcinnovex2/pcinnovex2/settings.py
Reiniciar Gunicorn:
sudo systemctl restart pcinnovex2-gunicorn
