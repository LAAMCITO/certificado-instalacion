# Roadmap

## Corto Plazo

- Completar las pantallas faltantes de la TUI.
- Sincronizar el guardado de todas las secciones del modelo.
- Agregar validaciones más estrictas por campo.
- Mejorar la carga y edición de certificados existentes.

## Mediano Plazo

- Implementar la generación de PDF a partir del JSON.
- Incorporar evidencias de forma más estructurada.
- Separar mejor el modelo de dominio de las estructuras temporales de edición.
- Agregar pruebas automáticas para los flujos de guardado y carga.

## Largo Plazo

- Soportar búsqueda avanzada de certificados.
- Mejorar el historial de cambios.
- Evaluar exportación adicional a otros formatos si el uso interno lo requiere.

## Criterio De Priorización

- Primero se completa lo que bloquea el flujo operativo real.
- Luego se endurecen validaciones y consistencia del modelo.
- Después se atacan salidas documentales y mejoras de experiencia.
